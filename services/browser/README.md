# «Браузер» — com.user.browser 2.x (власний браузер)

Свій інтерфейс повністю: рядок вкладок, адресний рядок, закладки, історія, стартова сторінка. Сайти відкриваються
у вкладках-`<iframe name="tabN">` всередині застосунку. Рушій — Chromium 120 WebAppMgr (той самий, на якому працюють
усі веб-застосунки ТВ); браузер LG не використовується (його файли повернуто до стоку).

## Як це працює
- Сайти забороняють вбудовування (`X-Frame-Options`, CSP `frame-ancestors`) → WAM показав би «помилка -27».
  **`service/framegate.py`** (хук 43) підключається до DevTools WebAppMgr (127.0.0.1:9998, LG вмикає його на ТВ) і
  ЛИШЕ для нашого застосунку та ЛИШЕ для документів вкладок віддає відповідь без цих заголовків
  (`Fetch.getResponseBody` → `Fetch.fulfillRequest`; `continueResponse` у цій збірці не спрацював). Стосується
  ВСІХ фреймів у браузері, і вкладених фреймів самих сайтів теж: їхнє `SAMEORIGIN` порівнюється з нашою сторінкою
  (file://) і інакше блокується.
- **WAM замінює весь застосунок своєю сторінкою помилки (`loaderror.html`, «-27»), щойно будь-який фрейм не
  завантажився** (напр. рекламний фрейм сайту, відрізаний блокувальником) → сервіс блокує завантаження цієї сторінки
  в наш застосунок (`Fetch.failRequest`), невдалий фрейм просто лишається порожнім.
- Він же: повідомляє застосунку переходи й заголовки вкладок (`__fgRecv`), виконує назад/вперед/оновити у вкладці
  (застосунок → binding `__fgSend`), і пересилає кнопки пульта, натиснуті НА сайті (BACK, кольорові) та
  `window.open` / `target=_blank` (→ нова вкладка) — бо документ сайту для застосунку чужий.
- Фрейми вкладок на цьому ТВ живуть у процесі застосунку (не OOPIF) → контексти за `Runtime.executionContextCreated`;
  OOPIF-шлях теж є.
- Застосунок не створює жодного фрейму, поки сервіс не скаже «готово» (`window.__framegate`).
- Пам'ять ТВ: живих сайтів ≤ 3, старіші вкладки вивантажуються й перезавантажуються при поверненні.
- Масштаб сторінок 100–200 % (кнопка у панелі; за замовчуванням 150 %, як у браузері LG).

## Керування
На сайті: курсор як завжди; 🔴 — панель (фокус на адресі, панель блимає), 🔴🔴 — одразу ввести адресу (виділена), 🟢 — нова вкладка, 🟡/🔵 — сусідня вкладка,
Back — назад по історії. У панелі: стрілки/OK; на вкладці 🔴 — закрити її. Поля пошуку/адреси мають кнопку →
(не треба знову відкривати клавіатуру); → з кінця тексту теж веде на неї. Стартова сторінка: пошук, закладки, часто
відвідувані; на плитці ✕ (з'являється при наведенні/фокусі) або 🔴 — прибрати. ☆ — закладка поточного сайту.
⚙ — налаштування: масштаб сторінок (‹ › 100–250 %), пошукова система (DuckDuckGo / Startpage / Google / Bing),
тема (як у хабі / темна / світла; хаб публікує свою в settings myhome/uiTheme), очистити історію (OK двічі).
Закладку прибирає друге натискання 🔴/✕ (за 3 с), історію — перше. ⛶ — повний екран (🔴 повертає панель).
Розширень Chrome Web Store немає: WebAppMgr їх не підтримує (можна додати свої скрипти для сайтів через сервіс).

## Файли
`app/` (застосунок), `service/cdp.py` (мінімальний DevTools-клієнт без залежностей), `service/framegate.py`,
`deploy/init.d/43-browser.sh`, `build.ps1`, `deploy.ps1` (ставить застосунок + сервіс + хук), `tv-install.sh`
(при встановленні один раз експортує закладки браузера LG у `lgbookmarks.js` — лише на ТВ).
Лог: `/media/developer/myhome-browser/framegate.log`. Вимкнути сервіс: `touch .../framegate.off`.

## Безпека
Сервіс змінює заголовки лише для фреймів нашого браузера. Захист від «clickjacking» для сайтів у ньому не діє —
наш застосунок сам їх показує, сторонніх сторінок-обгорток тут немає. Порт 9998 відкрила LG (на всіх інтерфейсах);
сервіс підключається до нього локально.
