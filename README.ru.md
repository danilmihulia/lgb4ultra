# lgb4ultra — свой интерфейс для LG OLED B4 (2024)

Полностью свой интерфейс для одной модели телевизора. Свои вместо LG: главный экран, заставка, браузер, баннеры входов, системные окна и
экранная клавиатура. Без рекламы и рекомендаций LG, быстро и минималистично. Обработку картинки, HDMI, защиту OLED,
DRM и саму прошивку проект **не трогает**.

🇬🇧 [English — README.md](README.md)

> ⚠️ **Сначала прочитай [отказ от ответственности](#отказ-от-ответственности).** Нужен рут. Всё проверено на **одном**
> телевизоре; за свой отвечаешь ты сам. Всё обратимо, но рут и системные изменения всегда несут риск.

## Что получишь

| | |
|---|---|
| **Хаб** (главный экран) | Вместо LG Home и кнопки HOME: категории, избранное, перетаскивание, поиск, выбор входа, свои настройки (картинка по входам, звук, таймеры, приватность, кнопки пульта), 10 языков, тёмная/светлая тема, меню «Живлення» по долгому POWER. |
| **Заставка** | Свои обои слайд-шоу с часами; заменяет и фото LG «Нет сигнала» на HDMI. |
| **Браузер** | Свой: вкладки, закладки, история, стартовая страница, масштаб, видео на весь экран. Браузера LG нет. |
| **Файлы** | Флешки, обои, корзина, поиск, встроенный видео- и аудиоплеер, импорт обоев с флешки. |
| **Каналы** | Бесплатные открытые IPTV-плейлисты ([iptv-org](https://github.com/iptv-org/iptv)) с телепрограммой; заменяет «Прямое ТВ» LG, открывается кнопками GUIDE / TV. Можно добавить свои M3U-ссылки. |
| **Система** | Окна, уведомления и окно флешки LG в стиле хаба, своя экранная клавиатура (цветные кнопки пульта работают), без баннеров входов LG, кнопки пульта → наши экраны (SETTINGS, SOURCE, GUIDE, цифры, кнопки приложений на выбор). |
| **Загрузка** | Без хаба LG при включении: чёрный экран, потом наш хаб (~40 с). Логотип LG выключен. Включение через PS5 (HDMI-CEC) — сразу на консоль. |
| **Приватность** | Блокировка рекламы и трекеров на весь телевизор (`/etc/hosts`), рекламные/следящие настройки LG и «умные советы» выключены. |

## Подойдёт ли мой телевизор?

**Собрано и проверено только на:**

- LG **OLED B4** (2024), модель `OLEDxxB4…` (проверено: a 55″ OLED55B4)
- прошивка **33.31.x** (проверено: 33.31.75), webOS **25** (внутри — webOS 10.3)

Установщик это проверяет и на чём-то другом останавливается. Другие модели LG 2024 на той же платформе *могут*
заработать с `--force`, но никто не пробовал — не делай этого, если не умеешь восстанавливать рутованный телевизор.

> ❗ **Не обновляй прошивку.** В прошивках примерно после 10 октября 2026 LG закрыла уязвимость, через которую делается рут.
> После обновления рут больше не сделать (сброс к заводским настройкам тоже может его забрать). Выключи автообновление
> (Настройки → Поддержка → Обновление ПО; названия пунктов могут немного отличаться) и включи «Block system updates»
> в Homebrew Channel (шаг 3).

## Что нужно

- телевизор и компьютер (Windows, macOS или Linux) **в одной домашней сети**;
- на компьютере: [Python 3.8+](https://www.python.org/downloads/) (для рута), [Node.js 18+](https://nodejs.org/)
  (для нашего установщика), клиент OpenSSH (уже есть в Windows 10/11, macOS и Linux);
- около 30 минут.

## Установка

### 1. Проверь телевизор

Настройки → Поддержка → Обновление ПО (или «Об этом телевизоре»): **версия прошивки** должна быть `33.31.xx`.
Модель там же или на наклейке сзади. Запиши **IP-адрес** телевизора (Настройки → Сеть → Wi-Fi/проводная →
Дополнительно), например `192.168.1.50`.

### 2. Рут через SlopBro

[SlopBro](https://github.com/throwaway96/slopbro) (автор throwaway96) получает root через ошибку в webOS и ставит
[Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel). Прошивку и загрузчик он **не трогает**.
Мы его не распространяем — скачивай у автора:

1. Скачай SlopBro: <https://github.com/throwaway96/slopbro> → зелёная кнопка **Code** → **Download ZIP** (или страница
   [releases](https://github.com/throwaway96/slopbro/releases)), распакуй.
2. Телевизор включён и подключён к интернету (по ходу он скачивает Homebrew Channel).
3. На компьютере, в папке SlopBro:
   ```
   python3 slopbro.py 192.168.1.50
   ```
   (Windows: `python slopbro.py 192.168.1.50`; подставь IP своего телевизора.)
4. **Подтверди запрос на подключение на телевизоре** пультом. Дождись конца — в списке приложений появится
   **Homebrew Channel**.
5. Не получается — читай README SlopBro: `--local-ip <IP компьютера>`, если телевизор не достучался до компьютера
   (разреши Python в брандмауэре), `--webos-version`, `--debug`. Не открывай там issue только чтобы сказать «сработало».

Подробнее о руте LG: [webosbrew.org](https://www.webosbrew.org/guides/rooting/), [cani.rootmy.tv](https://cani.rootmy.tv).

### 3. Настройки Homebrew Channel

Открой **Homebrew Channel** на телевизоре → **Settings**:

- **Root status** должен быть *ok*;
- **включи**: *SSH server*, *Block system updates*;
- **выключи**: *Telnet* (он без пароля).

Перезагрузи телевизор один раз (удержать POWER или выдернуть из розетки на 30 с) и проверь, что рут на месте.

### 4. Скачай этот проект

```
git clone https://github.com/danilmihulia/lgb4ultra.git
cd lgb4ultra
```
(или зелёная кнопка **Code** → **Download ZIP**, распакуй, открой терминал в папке.)

### 5. SSH-ключ (один раз)

```
node install/setup-ssh-key.js 192.168.1.50
```
Создаёт на компьютере `~/.ssh/lgb4ultra_ed25519` и один раз спрашивает пароль root телевизора: у Homebrew Channel по
умолчанию **`alpine`**. Дальше компьютер входит по ключу. Никому не давай этот ключ — это полный доступ к телевизору.

### 6. Сначала пробный прогон (ничего не меняет)

```
node install/install.js 192.168.1.50 --key ~/.ssh/lgb4ultra_ed25519 --dry-run
```
Проверит модель и прошивку, прочитает оригинальные файлы LG с твоего телевизора, соберёт правленые копии и наши
приложения у тебя на компьютере и покажет, что установит. В PowerShell путь к ключу пиши как
`"$HOME\.ssh\lgb4ultra_ed25519"`.

### 7. Установка

```
node install/install.js 192.168.1.50 --key ~/.ssh/lgb4ultra_ed25519
```
Ответь `y` и дай перезагрузить телевизор. После перезагрузки экран какое-то время чёрный, потом появляется **наш хаб**.

Опции: `--no-early` (обычная загрузка LG, наш хаб сменит её секунд через 35), `--no-sm-restart` (оставить логотип
загрузки; окна LG будут серыми до следующего перезапуска оболочки), `--no-adblock`, `--no-privacy` (не трогать
рекламные/следящие настройки LG), `--yes` (не спрашивать).

### 8. Первые шаги

- **Обои:** скинь картинки на флешку → вставь → «Открыть в Файлах» → выбери папку → «Скопировать все в обои».
- **Настройки:** ⚙ в хабе (или кнопка SETTINGS): язык, тема, картинка, кнопки, заставка…
- **Пульт:** HOME — хаб · SETTINGS — настройки хаба · SOURCE — входы · GUIDE — Каналы · удержать POWER — меню
  «Живлення» · в браузере 🔴 — адресная строка, 🟢 — новая вкладка, 🟡/🔵 — соседняя вкладка.

## Удаление

```
node install/uninstall.js 192.168.1.50 --key ~/.ssh/lgb4ultra_ed25519
```
Убирает наши хуки загрузки и приложения, всё размонтирует, возвращает в работу файлы LG и перезагружает телевизор →
обычный интерфейс LG. `--purge` удаляет и наши папки с данными (обои тоже). Рут и Homebrew Channel остаются
(их убирают в самом Homebrew Channel).

Если телевизор когда-нибудь не запустится нормально: **аварийный режим** Homebrew Channel (включается сам после
сбоя при загрузке) пропускает все наши хуки и ранний запуск → телевизор стартует с обычным интерфейсом LG; потом
запусти удаление.

## Как это устроено

В системном образе LG (он только для чтения) ничего не меняется. Наши файлы лежат в `/media/developer`,
`/var/lib/myhome` и `/var/lib/webosbrew/init.d` и при загрузке **подключаются поверх** оригинальных (bind-mount);
отключил — снова оригинал. Файлов LG в репозитории нет: установщик читает их с **твоего** телевизора и правит на ходу
скриптами из `tv/`. Подробнее: [docs/how-it-works.md](docs/how-it-works.md) (на английском).
