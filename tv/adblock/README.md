# Блокування реклами й трекерів (хук 42)
`adblock.py` (на ТВ: `/media/developer/myhome-adblock/`) дописує список Peter Lowe (~3.5k рекламних/трекінгових доменів)
у `/etc/hosts` і в копії `/var/palm/jail/*/etc/hosts` (їх читає, зокрема, браузер LG). `/etc/hosts` — tmpfs, відновлюється
при кожному завантаженні, тож у системі нічого постійно не змінюється. Оновлення списку — щотижня.
- Чому не великий список: 76k доменів (StevenBlack) = +40 мс на КОЖЕН DNS-запит усіх застосунків; 3.5k = +2 мс.
- Винятки: `allow.txt` (домен на рядок). Лог: `adblock.log`.
- Вимкнути: `touch /media/developer/myhome-adblock/adblock.off` (секція прибирається за хвилину) або видалити хук.
- Також стежить, щоб DuckDuckGo лишався пошуком у браузері LG (див. browser/README.md).
- Перевірено 2026-11-22: заблокований домен у браузері LG — «Ця веб-сторінка недоступна», хоча DNS його резолвить.
