# How it works

The system image of the TV (`/` squashfs, `/usr` overlay) is read-only and is never changed. Root comes from
Homebrew Channel, which runs every script in `/var/lib/webosbrew/init.d` at boot (and skips them in its failsafe
mode). Our files live on the writable flash and are **bind-mounted over** LG's files, so `umount` = stock again.

## What goes where on the TV

| On the TV | From | Purpose |
|---|---|---|
| `/media/developer/myhome-home/` | `apps/hub` | the hub; bind-mounted over `/usr/palm/applications/com.webos.app.home` (LG's home app id is kept, so HOME, SAM, `keepAliveApps` all treat it as the home) |
| `/media/developer/myhome-saver/` | `apps/saver` | screen saver; over `com.webos.app.screensaver`; wallpapers shared with the hub (`walls/`, `walls.json`, `walls-screen/` = screen-size copies of huge images) |
| `/media/developer/apps/usr/palm/applications/com.user.*` | `apps/browser`, `apps/explorer`, `apps/iptv` | normal developer apps (installed as .ipk) |
| `/media/developer/myhome-keyfilter/` | `tv/keyfilter` | our key filter, first in surface-manager's chain (HOME, SETTINGS, SOURCE, GUIDE, ⋯, digit / app button bindings) — a patched `com.webos.surfacemanager.json` over `/etc/configd/layers/base/` |
| `/media/developer/notif-patched/` | generated by `tv/notif-restyle` | LG's pop-ups / toasts / USB card in our style; over `/usr/lib/qml/SystemUI/Notification` |
| `/media/developer/inputcommon-patched/qml/` | generated by `tv/inputcommon-patch` | HDMI «no signal» → our saver, no LG input banners; over the input app's `qml/` |
| `/media/developer/maliit-qml/` | generated by `tv/maliit-restyle` | our on-screen keyboard; over `/usr/lib/maliit/plugins/qml` |
| `/media/developer/myhome-poweron/` | `tv/poweron`, `services/epg` | hub on remote power-on (not on PS5/CEC), POWER-hold menu (`pwrkey.py`), «Channels» instead of Live TV, the UI language/theme for our apps, programme guide refresh |
| `/media/developer/myhome-browser/` | `services/browser` | browser helper: lets sites open in the browser's own tabs (via WebAppMgr DevTools on 127.0.0.1:9998, only for our browser's frames) |
| `/media/developer/myhome-adblock/` | `tv/adblock` | ad/tracker hosts list added to `/etc/hosts` (tmpfs, rebuilt each boot) |
| `/var/lib/webosbrew/init.d/*.sh` | `tv/hooks` | boot hooks that mount / start all of the above |
| `/var/lib/myhome/`, `/var/systemd/system/env/criu_remove_img.env` | `tv/early-takeover` | early takeover: an `LD_PRELOAD` library in a tiny LG boot service mounts our hub at ~13 s so LG's hub never shows; does nothing in failsafe mode |

## Patching LG's files without shipping them

`install/install.js` reads the original files from the TV through a **non-recursive** bind mount of `/usr` (it shows
what is underneath our mounts), patches them on the PC with the scripts in `tv/*/` and copies the result back. Every
replacement is count-checked, so a different firmware fails loudly instead of producing a broken file.

## Boot

1. ~5 s LG's boot animation; ~13 s our library (in `criu_remove_img.service`) mounts the hub and saver, runs
   `early.sh` (mounts the patches, restarts the compositor so it loads them, makes SAM re-read the two apps).
2. ~19 s LG's first app comes up: after a PS5 (HDMI-CEC) power-on it is left alone, otherwise our hub is launched.
3. ~35 s Homebrew Channel runs `init.d`: the hooks are idempotent and only start the background services.
